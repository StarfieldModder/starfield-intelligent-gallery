⭐ Summary — Installation & Setup Instructions for Starfield Intelligent Gallery

Below is a consolidated, accurate overview of what the repository documents describe about installing, preparing, and running the SIG application.

🌌 1. What the App Is

The Starfield Intelligent Gallery (SIG) is a modular, offline-first desktop application for browsing and analyzing Starfield screenshots. It includes:

  • Image browser

  • Dynamic filtering

  • Metadata inspector

  • Modal viewer

  • Slideshow mode

  • Favorites system

  • Batch operations

  • Optional holographic UI effects

🗂️ 2. Repository Structure (Relevant to Setup)

From the repo root:

  • GalleryApp/ → The actual application code (Python modules + launcher)

  • data/ → User’s personal image folder (empty by default; you add your own images)

  • sample_images/ → Example images

  • ui/, core/, Logos/ → Internal assets

🛠️ 3. Installation Requirements

✔️ Python

You need a working installation of Python 3.x.

✔️ Required Python Packages

The app uses:

  • Pillow (image loading, JPG/PNG/DDS support)

  • exifread (metadata extraction)

  • keyboard (optional hotkeys)

These are typically installed via:

Code
pip install Pillow exifread keyboard

📁 4. Preparing Your Image Library

The data/ folder is your personal gallery folder. The repo’s data/README.md states:

  • Supported formats: jpg, jpeg, png, bmp, tiff, gif, webp

  • Add your own images here

  • Images load automatically when this folder is selected

  • Images appear in random order on startup

You can also point the app to your Starfield screenshot directory, which it auto-detects by default.

▶️ 5. Running the Application

The launcher file is:

Code
GalleryApp/starfield_gallery.py

To run it:

Option A — Double-click

If .py files are associated with Python, double-clicking launches the app.

Option B — Terminal

Navigate to the repo folder and run:

Code
python GalleryApp/starfield_gallery.py

This opens the full UI:

  • Folder tree

  • Image grid

  • Metadata panel

  • Modal viewer

  • Slideshow controls

📦 6. First-Run Behavior

When the app launches:

  • It loads images from the default Starfield screenshot directory

  • You can switch folders using the UI

  • Metadata appears automatically when selecting an image

  • Favorites persist between sessions

  • Slideshow and modal viewer are available immediately
