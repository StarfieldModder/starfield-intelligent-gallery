RestorePanel(QWidget)
  • Main UI panel with holographic design
  • Backup source selector (SSD/HD)
  • Progress bar, status label, output display
  • Buttons: RESTORE, VERIFY, CANCEL

RestoreWorker(QObject)
  • Async restore orchestration in separate thread
  • Workflow: pre-check → snapshot → verify → restore → integrity → notify
  • Emits: progress_updated, status_changed, error_occurred, complete

IntegrityChecker
  • SHA256 hash computation for files
  • Directory scanning and manifest management
  • Verification against manifest
  • Methods: compute_hash(), scan_directory(), verify()

GitSnapshotManager
  • Creates Git snapshots before restore
  • Enables atomic rollback if needed
  • Methods: create_snapshot(), get_latest_commit()

GuardianAINotifier
  • Sends notifications to Guardian AI companion
  • Writes to C:\IG\logs\companion_notifications.log
  • Methods: notify(), _generate_message()

 RESTORE WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User selects backup source (SSD or HD) in dropdown
2. User clicks "RESTORE" button
3. Confirmation dialog shown
4. RestoreWorker thread starts (async)
   └─ Pre-checks: verify source exists, Git repo initialized
   └─ Create snapshot: Git commit for rollback point
   └─ Verify backup: integrity check of source files
   └─ Restore files: copy from backup to C:\IG (skip preserved patterns)
   └─ Verify integrity: hash check of restored files
   └─ Notify Guardian: write to companion_notifications.log
5. Complete signal emitted with RestoreReport
6. RestorePanel displays detailed report
   └─ Status, files restored, errors, warnings, snapshot commit

RestoreReport contains:
  • status: RestoreStatus (COMPLETE, FAILED, ROLLED_BACK, etc.)
  • source: RestoreSource (SSD or HD)
  • timestamp: datetime of operation start
  • files_restored: int count
  • files_checked: int count
  • integrity_passed: bool
  • snapshot_commit: str (Git commit hash)
  • guardian_notified: bool
  • errors: List[str]
  • warnings: List[str]
  • rollback_executed: bool
  • rollback_point: str (Git commit hash)

Source Not Found
  → Verify backup path connected
  → Check drive letter assignment
  → Update BACKUP_SSD/BACKUP_HD if needed

Backup Verification Failed
  → Core modules missing or corrupted
  → Restore cannot proceed safely
  → Use Recovery Dashboard to verify backup

Restore Stuck
  → Click Cancel button to abort
  → Restore will rollback to pre-restore snapshot
  → Check Windows Task Manager if unresponsive

Guardian AI Notification Failed
  → Check C:\IG\logs\ directory exists
  → Error won't block restore operation
  → Files already copied will remain
